# 销售资料库 · 微信小程序

销售员在微信里直接查看所负责品牌的资料，并可一键把资料文件转发给客户。
资料的维护仍在网页管理后台完成，小程序与网页版共用同一个服务端，数据实时一致。

## 功能

- **登录**：第一次用账号密码登录，并自动绑定当前微信；之后打开小程序即自动登录。“退出登录”会解除绑定
- **资料列表**：按品牌、分类筛选，关键字搜索；“新”/“已更新”标记，底部“资料”标签显示未读数；下拉刷新，前台时每 30 秒自动刷新
- **打开查看**：PDF / Word / Excel / PPT 在小程序内直接打开，图片、视频用微信预览；始终是最新版本
- **转发给客户**：把资料文件直接发到微信聊天（客户收到的是文件本身，不需要登录）
- **微信更新提醒**：市场部发布新资料或替换文件时，通过微信“订阅消息”通知负责该品牌的销售员，点击消息直达资料详情

## 上线步骤

### 1. 注册小程序

在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序，建议使用**企业主体**。
在「开发管理 → 开发设置」中获取 **AppID** 和 **AppSecret**。

### 2. 部署服务端（HTTPS）

小程序只能访问 **HTTPS + 已备案域名** 的服务器。按根目录 README 部署服务端，并设置以下环境变量：

| 变量 | 说明 |
| --- | --- |
| `WX_APPID` | 小程序 AppID |
| `WX_SECRET` | 小程序 AppSecret（只放在服务端，不要写进小程序代码） |
| `WX_TEMPLATE_ID` | 订阅消息模板 ID（见第 4 步，不配置则不发送提醒） |
| `WX_TEMPLATE_FIELDS` | 模板字段映射，JSON 格式，见第 4 步 |
| `WX_MINIPROGRAM_STATE` | 点击提醒后打开的版本：`formal` 正式版（默认）/ `trial` 体验版 / `developer` 开发版 |

未配置 `WX_APPID` / `WX_SECRET` 时，小程序仍可用账号密码登录，只是没有自动登录和微信提醒。

### 3. 配置服务器域名

公众平台「开发管理 → 开发设置 → 服务器域名」中，把服务端域名同时加入：

- **request 合法域名**
- **downloadFile 合法域名**

### 4. 选择订阅消息模板

公众平台「功能 → 订阅消息」中，从公共模板库选一个“资料更新 / 内容更新”类的**一次性订阅**模板，
记下模板 ID 和字段名（如 `thing1`、`time3`），把字段映射到下列取值来源：

| 来源 | 内容 |
| --- | --- |
| `title` | 资料标题 |
| `brand` | 品牌 |
| `category` | 分类（价格表、培训文件等） |
| `action` | 动作：发布了新资料 / 更新了资料文件 |
| `time` | 更新时间（北京时间） |
| `note` | 版本说明 |

默认映射为：

```bash
WX_TEMPLATE_FIELDS='{"thing1":"title","thing2":"brand","time3":"time","thing4":"action"}'
```

请按实际模板的字段名修改。超过微信长度限制的内容（如 `thing` 类型最多 20 字）会被自动截断。

> 一次性订阅的规则：销售员每点一次“允许”，可以收到一条提醒。
> 销售员在弹窗中勾选“总是保持以上选择”后，之后不再弹窗，打开资料时会自动续订。
> 小程序会在剩余次数较少时自动请求续订，「我的」页面也可以手动增加提醒次数。

### 5. 修改小程序配置并上传

1. `miniprogram/config.js`：把 `baseUrl` 改成服务端地址，例如 `https://sales.example.com`
2. `miniprogram/project.config.json`：把 `appid` 改成你的 AppID
3. 用 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 打开 `miniprogram` 目录，预览后点击“上传”
4. 在公众平台提交审核。因为需要登录才能使用，请在**审核备注中提供一个测试销售员账号**
   （可在管理后台新建一个只分配了演示品牌的账号）

### 本地调试

1. 在项目根目录运行 `npm start`（默认 http://localhost:3000）
2. 在开发者工具「详情 → 本地设置」中勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”
3. `config.js` 中 `baseUrl` 暂时改为 `http://localhost:3000`
4. 本地没有配置 `WX_APPID` 时，用账号密码登录即可；真机调试需要把 `localhost` 换成电脑的局域网 IP

## 目录结构

```
miniprogram/
  app.js / app.json / app.wxss   全局入口、页面与 tabBar 配置、公共样式
  config.js                      服务端地址
  utils/api.js                   请求封装、登录态、下载 / 打开 / 转发文件、订阅提醒
  pages/login                    登录
  pages/index                    资料列表（tab：资料）
  pages/detail                   资料详情（订阅消息点击后也打开这里）
  pages/me                       个人信息、负责品牌、微信提醒、修改密码、退出（tab：我的）
```
