# 部署到阿里云服务器（手把手教程）

整个过程分两个阶段：

| 阶段 | 做完之后 | 需要时间 |
| --- | --- | --- |
| **阶段一：买服务器并安装** | 销售员用手机或电脑浏览器访问 `http://服务器IP` 就能用 | 约 30 分钟 |
| **阶段二：域名 + 备案 + HTTPS** | 有正式网址 `https://sales.你的域名.com`，数据加密传输，可以上线微信小程序 | 备案审核一般 1～3 周 |

建议先做完阶段一，找几个销售员试用。同时提交备案，备案通过后再做阶段二，然后正式推广。

---

## 阶段一：买服务器并安装

### 1. 购买服务器

1. 登录 [阿里云](https://www.aliyun.com/)（没有账号先注册，并完成**企业实名认证**；后面备案和小程序都需要企业主体）
2. 搜索并进入 **轻量应用服务器**，点击“立即购买”。它比 ECS 云服务器简单，适合这个项目
3. 按下面的要求选择：
   - **地域**：选离你们最近的国内城市，例如华东 1（杭州）、华东 2（上海）、华北 2（北京）或华南 1（深圳）。**不要选香港或海外**，否则无法备案，也就无法上线小程序
   - **镜像**：选“系统镜像”里的 **Ubuntu 22.04** 或 **Ubuntu 24.04**（一定要选 Ubuntu）
   - **套餐**：2 核 CPU、2GB 内存就够用（销售员很多或文件很大时选 4GB）。**硬盘要能放下你们的所有资料**，并预留一倍空间给历史版本
   - **购买时长**：建议**至少 3 个月**，最好 1 年。阿里云规定服务器买满 3 个月才能申请备案
4. 付款。价格以购买页面为准，新用户通常有优惠

### 2. 放行端口

在轻量应用服务器控制台点进刚买的服务器 → 左侧 **防火墙** → **添加规则**，放行以下两个端口：

| 应用类型 | 端口 |
| --- | --- |
| HTTP | 80 |
| HTTPS | 443 |

（22 端口默认已放行，用于远程登录，不用动。）

> 买的如果是 **ECS 云服务器**：在“安全组”中添加入方向规则，放行 80 和 443 端口。

### 3. 下载程序压缩包

1. 在自己电脑上下载：<https://github.com/brucexu666888/-/archive/refs/heads/claude/sales-materials-app-c3hjo4.zip>
2. 把下载好的文件**重命名为 `sales.zip`**（这一步是为了后面的命令简单）

### 4. 登录服务器，上传压缩包

1. 在服务器控制台点击 **远程连接**，选择 **Workbench 一键连接**，会在浏览器里打开一个黑色的命令行窗口
   - 如果提示输入密码，先回到控制台点“重置密码”，设置 root 密码后再连接
2. 在 Workbench 窗口顶部菜单找到 **文件 → 打开新文件树**（或“上传文件”），把 `sales.zip` 上传到 **`/root`** 目录

### 5. 运行安装脚本

在黑色命令行窗口里**逐行**复制下面的命令，每粘贴一行按一次回车：

```bash
cd /root
apt-get install -y unzip
unzip -o -q sales.zip
cd /root/*sales-materials-app*/
bash deploy/install.sh
```

脚本会自动完成：安装 Node.js 和 Nginx、安装程序、设置开机自动启动、配置网站。大约需要 3～5 分钟。

结束时会显示：

```
==============================================================
  安装完成！
  访问地址：http://47.xx.xx.xx
  管理员账号：admin
  管理员密码：xxxxxxxxxxxx
==============================================================
```

**请立即把管理员密码抄下来**（这个密码只在第一次安装时显示一次）。

### 6. 开始使用

1. 在浏览器打开显示的访问地址，用 admin 和刚才的密码登录，点右上角“改密码”改成你自己的密码
2. 在“品牌管理”里建品牌，在“销售员管理”里建账号并勾选负责的品牌，在“资料管理”里上传资料
3. 把网址和账号发给销售员。建议他们在手机浏览器里点“添加到主屏幕”，以后像 App 一样打开

> ⚠️ 阶段一使用的是 `http://`，数据没有加密。可以先小范围试用，**正式推广前请完成阶段二**。

## 阶段二：域名 + 备案 + HTTPS

### 1. 购买域名

在阿里云搜索 **域名注册**，买一个域名（例如 `yourcompany.com`）。购买后按提示完成域名实名认证。
已经有公司域名的话可以直接用，例如 `sales.公司域名.com`。

### 2. ICP 备案

在国内服务器上用域名访问网站，必须先完成 ICP 备案。

1. 在阿里云搜索 **ICP 备案**，进入备案系统，按提示填写（主体选公司，用上面买的服务器申请备案服务码）
2. 阿里云初审后，还要经过管理部门（管局）审核。整个过程一般需要 1～3 周，以短信通知为准
3. 备案通过后 30 天内，按要求到“全国互联网安全管理服务平台”办理公安备案

### 3. 解析域名

在阿里云 **云解析 DNS** 中找到你的域名 → **添加记录**：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| A | `sales`（网址就是 `sales.你的域名.com`） | 服务器公网 IP |

### 4. 开启 HTTPS

用 Workbench 登录服务器，运行下面的命令（把域名换成你自己的）：

```bash
cd /root/*sales-materials-app*/
bash deploy/install.sh sales.你的域名.com
```

脚本会自动申请免费的 HTTPS 证书（证书会自动续期），并把 `http://` 访问自动跳转到 `https://`。
完成后用 `https://sales.你的域名.com` 访问即可。原来的数据和账号都不会丢失。

### 5. 上线微信小程序（可选）

有了 HTTPS 域名后，就可以按 [miniprogram/README.md](../miniprogram/README.md) 上线小程序。
小程序的 AppID 等配置写在服务器的配置文件里，修改方法：

```bash
nano /etc/sales-library.env      # 去掉 WX_ 开头几行前面的 #，填好值；Ctrl+O 回车保存，Ctrl+X 退出
systemctl restart sales-library
```

## 日常维护

### 备份（强烈建议开启）

在服务器控制台找到 **快照** → 设置 **自动快照策略**（例如每天一次，保留 7 天）。
这样即使误删了资料或服务器出问题，也能恢复到之前的状态。

### 升级到新版本

1. 按阶段一第 3、4 步，下载新的压缩包，重命名为 `sales.zip`，上传到 `/root` 并覆盖原文件
2. 运行下面的命令。**已经配置了域名的，最后一行要带上域名**：

```bash
cd /root
rm -rf /root/*sales-materials-app*/
unzip -o -q sales.zip
cd /root/*sales-materials-app*/
bash deploy/install.sh sales.你的域名.com
```

数据、账号和配置都会保留。

### 忘记管理员密码

```bash
cd /opt/sales-library
sudo -u saleslib env DATA_DIR=/var/lib/sales-library node scripts/reset-password.js admin 新密码
```

### 常用命令

| 用途 | 命令 |
| --- | --- |
| 查看是否在运行 | `systemctl status sales-library` |
| 查看最近的日志（出问题时发给技术人员） | `journalctl -u sales-library -n 100` |
| 重启 | `systemctl restart sales-library` |
| 查看硬盘剩余空间 | `df -h /` |

### 常见问题

- **浏览器打不开 `http://IP`**：检查防火墙（安全组）是否放行了 80 端口；在服务器上运行 `systemctl status sales-library` 看是否为 `active (running)`
- **上传大文件失败**：默认单个文件最大 200MB。要调大的话，在 `/etc/sales-library.env` 中修改 `MAX_UPLOAD_MB`，重启服务后，再修改 `/etc/nginx/sites-available/sales-library` 里的 `client_max_body_size`，然后运行 `systemctl reload nginx`
- **申请 HTTPS 证书失败**：确认备案已通过、域名已解析到服务器 IP（解析生效可能需要几分钟），并且 443 端口已放行
