# 把销售资料库安装到手机（发给销售员看）

销售资料库可以像 App 一样安装到手机桌面：有自己的图标，点开就是全屏界面，不显示浏览器地址栏。
**苹果和安卓手机都可以**，不需要去应用商店下载。

> 前提：公司的网址必须是 `https://` 开头（部署时已开启 HTTPS）。

## 苹果手机（iPhone）

1. 用 **Safari 浏览器** 打开公司发给你的网址（在微信里打开的，先点右上角「···」→「在浏览器中打开」）
2. 点屏幕底部中间的 **分享按钮**（一个方框，里面有向上的箭头）
3. 往下滑，点 **「添加到主屏幕」**，再点右上角「添加」
4. 回到桌面，点「资料库」图标打开，登录即可

## 安卓手机

1. 用手机自带的浏览器或 Chrome 打开网址（在微信里打开的，先点右上角「···」→「在浏览器中打开」）
2. 如果页面上出现 **「安装」** 按钮，直接点它
3. 没有这个按钮的话：点浏览器的 **菜单**（「⋮」或「≡」），选择 **「添加到主屏幕」** 或 **「添加到桌面」**
   （华为、小米等手机可能还需要在弹窗里允许「创建桌面快捷方式」）
4. 回到桌面，点「资料库」图标打开，登录即可

## 常见问题

- **登录一次后会一直保持登录**（30 天内），不用每次都输入密码
- **资料总是最新的**：每次打开都会从服务器获取最新资料；没有网络时会提示“网络不可用”
- **找不到“添加到主屏幕”**：换用手机自带浏览器或 Chrome；夸克、UC 等浏览器的菜单名称可能不同
