# 部署到极空间 NAS

可以部署在极空间上，用它自带的 **Docker** 功能运行。资料文件直接存在 NAS 的硬盘里。

## 先了解：NAS 和云服务器的区别

| | 极空间 NAS | 阿里云服务器 |
| --- | --- | --- |
| 费用 | 不用另外花钱 | 按年付费 |
| 硬盘空间 | 大、便宜 | 贵 |
| 公司内网使用 | ✅ 很方便 | ✅ |
| 销售员在外面用手机访问 | ⚠️ 需要额外配置（见第三部分） | ✅ 直接可用 |
| 下载速度 | 受家庭 / 公司宽带**上行**速度限制（通常 30～100Mbps，多人同时下载会变慢） | 取决于购买的带宽 |
| 微信小程序 | ❌ 家庭 / 普通宽带无法备案，**不能直接使用**（见第三部分方案 C） | ✅ 备案后可用 |
| 停电、断网 | 服务中断 | 不受影响 |

**建议**：如果销售员主要在公司里用，或者先试用，NAS 很合适。如果销售员经常在外面跑，而且要用微信小程序，
推荐用阿里云（[部署到阿里云.md](部署到阿里云.md)），或者采用本文第三部分的方案 C（NAS 存资料 + 阿里云转发）。

## 第一部分：安装

### 1. 确认 NAS 的处理器类型

在极空间 **设置 → 系统信息**（或“关于本机”）里查看处理器（CPU）型号：

- 型号里有 **Intel**、**AMD**、**赛扬**、**N100** 等字样 → 下载 **amd64** 版本
- 型号里有 **ARM**、**瑞芯微（Rockchip）**、**RK35xx** 等字样 → 下载 **arm64** 版本

### 2. 下载镜像文件

打开发布页面：<https://github.com/brucexu666888/-/releases/tag/nas-latest>，
下载对应的文件（约 60MB）：

- `sales-library-amd64.tar`（Intel / AMD）
- `sales-library-arm64.tar`（ARM）

**下载后不要解压**，把 `.tar` 文件直接上传到极空间里任意一个文件夹。

### 3. 导入镜像

打开极空间的 **Docker** 应用 → **镜像** → **本地镜像**（或“导入”）→ 选择刚上传的 `.tar` 文件。
导入完成后，镜像列表里会出现 `sales-library`，标签是 `latest`。

> 不同版本的极空间系统，菜单名称可能略有不同。找不到“导入”时，先把极空间系统升级到最新版本。

### 4. 准备数据文件夹

在极空间文件管理里新建一个文件夹，例如 **`销售资料库数据`**，用来保存数据库和所有上传的资料。
**请把它放在有备份的存储空间里**（例如开启了 RAID 1 或定时备份的硬盘）。

### 5. 创建容器

在 Docker 应用中选中 `sales-library` 镜像，点击 **创建容器**，按下面的表格设置：

| 设置项 | 填写 |
| --- | --- |
| 容器名称 | `sales-library` |
| 自动重启 / 开机自启 | **开启** |
| 文件夹映射（存储空间 / 卷） | 选择第 4 步建的文件夹 → 装载路径填 **`/data`** |
| 端口映射 | 本地端口填 **`3000`**（被占用时可以改成 `8080` 等）→ 容器端口填 **`3000`** |
| 环境变量 | 添加 `ADMIN_PASSWORD`，值为你想要的管理员初始密码 |

> 装载路径必须填 `/data`，否则容器删除或更新后，数据会丢失。

点击创建并启动。

> 如果你的极空间支持 **Compose**，也可以直接使用项目里的
> [deploy/nas/docker-compose.yml](../deploy/nas/docker-compose.yml)：放进一个文件夹，改好密码后启动即可。

### 6. 打开使用

在同一个局域网（公司 Wi-Fi）内的电脑或手机浏览器中打开：

```
http://NAS的内网IP:3000
```

NAS 的内网 IP 可以在极空间 **设置 → 网络** 里看到，一般是 `192.168.x.x`。
用账号 `admin` 和刚才设置的密码登录，然后点右上角“改密码”。之后的使用方法和其他部署方式完全一样。

## 第二部分：日常维护

### 备份

所有数据都在第 4 步建的文件夹里。备份这个文件夹就等于备份了全部资料和账号。
可以用极空间自带的备份功能，把它定期备份到另一块硬盘或云盘。

### 升级到新版本

1. 从发布页面下载新的 `.tar` 文件，按第一部分第 3 步导入。如果提示已存在，选择覆盖
2. 在 Docker 中**停止并删除**旧的 `sales-library` 容器（数据保存在 NAS 文件夹里，不会丢失）
3. 按第一部分第 5 步，用**完全相同的设置**重新创建容器

### 忘记管理员密码

在 Docker 应用中打开 `sales-library` 容器的 **终端**，输入下面的命令（`新密码` 换成你想要的密码）：

```
node scripts/reset-password.js admin 新密码
```

## 第三部分：让销售员在外面也能访问

在第一部分完成后，只有连着公司（或家里）网络的设备能访问。要让在外面跑业务的销售员也能用，有以下几种方案：

### 方案 A：宽带有公网 IP（适合懂一点网络的）

1. 打电话给宽带运营商，申请**公网 IPv4**（部分地区可以免费开通）
2. 在路由器上设置**端口转发**：外部端口（例如 `8443`）→ NAS 的内网 IP 和端口 `3000`
   （家庭宽带的 80、443 端口通常被运营商封锁，所以要用其他端口）
3. 配置 **DDNS 动态域名**：因为家庭宽带的 IP 会变，需要用一个域名自动跟随 IP 变化
4. **务必配置 HTTPS**，不要在公网上用 `http://` 传输账号密码

第 3、4 步可以借助极空间上常用的 Docker 工具（例如 Lucky）一次完成：它支持 DDNS、反向代理和自动申请 HTTPS 证书。

### 方案 B：内网穿透服务（最简单）

使用花生壳、cpolar 等内网穿透服务，把 NAS 的 `3000` 端口映射成一个外网地址。
不需要公网 IP，按服务商的说明操作即可。缺点是免费版带宽很小，传大文件会比较慢，正式使用建议购买付费版。

### 方案 C：NAS 存资料 + 阿里云转发（要用微信小程序时选这个）

微信小程序要求使用**已备案的 HTTPS 域名**，而家庭 / 普通宽带无法办理备案。如果需要小程序：

1. 买一台最便宜的国内阿里云服务器，用它办理域名备案
2. 在阿里云服务器和 NAS 之间搭建 frp 内网穿透，由阿里云服务器提供 HTTPS 域名，把请求转发到 NAS
3. 资料文件仍然存放在 NAS 上，阿里云服务器只负责转发

这个方案需要一定的技术能力。如果没有技术人员，更省心的做法是直接把系统部署到阿里云（见 [部署到阿里云.md](部署到阿里云.md)）。

### 安全提醒

- 只对外开放这一个端口，**不要**把极空间的管理页面直接暴露到公网
- 管理员和销售员都使用足够复杂的密码；销售员离职后立即在后台“停用”账号
